1The pattern

Every tag has three parts, joined by colons: site : kind : value.

PartWhat it isValues
SiteWhich Skilljar site the tag is fortest (test-continuous.skilljar.com), growth (growth.continuous.com), learn (learning.continuous.com)
KindWhat the tag doestopic, role, format, label, or a single-word tag such as featured
ValueWhich oneA word from the lists on this page

Why the site comes first: all Continuous Skilljar sites share one list of tags. Starting with the site keeps each site's tags apart. A tag without a site at the front is ignored, so older tags such as beginner cause no problems.

Use the Show tags for switch at the top: every tag on this page changes to that site, ready to copy.

5Writing a tag

1

Lower case, no spaces

A space splits a tag in two.

2

Colons between the parts

site, then kind, then value.

3

One-word values

permissionassist, not permission assist. A hyphen inside a value is fine.

4

Copy, don't type

One wrong letter makes a new tag that does nothing. Use the Copy buttons.

6Adding tags in Skilljar

Only published courses and paths can be tagged. Sign in to Skilljar as an admin, on the site you're tagging.

Create a tag and add courses to it

  1. Go to Domains & Publishing → Tags.
  2. Click New Tag and paste the tag exactly as copied from this page. If the tag already exists, click it instead.
  3. Click Published Courses (+), tick the courses and learning paths that should carry it, then Save.
  4. Reload the site's home page and check the items appear where you expect.

Or tag one course from its own page

  1. Course Management → Courses → the course.
  2. Manage Course → Publish course → Tags, and add the tags.

A new course also has to be listed on the site's main catalog page. The home page is built from the main catalog, so a tagged course that isn't listed there won't show.

7Learning paths

A learning path is one item, tagged exactly like a course.

Required

One tag.

Optional

Roles, a format, Featured and labels, same as a course.

Courses inside the path

Need no tags. Learners reach them through the path. Tag one only if it's also listed on the main catalog on its own.

8Checking your work

  1. Reload the home page. The item should sit under its topic, on its role cards, and in Featured if tagged.
  2. Look under "More". An item there has no topic tag, or a misspelt one.
  3. Run the tag check (for whoever maintains the theme): perl tools/check-tags.pl lists misspelt and unknown tags, items with two topics, and items under "More". Growth is private, so save its home page from a signed-in browser first and check the saved file.

9When something looks wrong

The item is in the wrong topicTwo topic tags, or the wrong oneKeep exactly one topic tag
A tag does nothingWrong site word, a typo, or a spaceDelete it and paste a copy from this page
A label doesn't showThe item isn't FeaturedAdd
A tag is on the wrong courseTicked by mistakeOpen the tag in Skilljar and untick the course. Don't delete a tag while other items still carry it.

Good to know: Skilljar removes the colons when it puts tags on the page, so growth:topic:opcon appears in the page code as growthtopicopcon. That's expected.
