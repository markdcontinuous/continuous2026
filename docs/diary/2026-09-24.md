## How we got to the Course Companion (the brainstorm)

**The problem.** A Teams thread with Merly's team was heading towards stripping the SCORM out of the AIT lessons and rebuilding them in another format. The reason underneath: they want Claude, through the Skilljar connector, to be able to read the course content, probably to use the courses as a knowledge base that answers questions. Mark's question: is that possible, and if we disassemble the SCORM, what format should it be, could it be an HTML course?

**What we established first.** Tested what the connector actually returns per lesson type. Text-block lessons (how BBE 101 is built): every word, headings, tables, key terms. Quiz questions and answers: yes. Uploaded Word or PDF files: yes, via a download link. Video: only the video's ID, nothing spoken. SCORM: title only. So the team's goal was real, and BBE 101 was the proof that a text lesson is fully readable.

**The tension.** Mark: "if we take SCORM out, all of these will be flat, boring documents." The slide kit gives split screens and slide-by-slide movement that Skilljar's text editor cannot. Converting would trade the learner experience for machine readability.

**The reframe.** You do not have to make that trade. Keep the SCORM lessons exactly as they are for learners and give Claude a readable copy alongside. Learners see the slides, Claude reads the text, nobody needs both. Three ways to do the readable copy were laid out:
1. Point Claude at the source files on disk (every SCORM started as an HTML file we still have). Complete, editable, no connector needed. Claude's recommendation if the team only wants Claude to know the content.
2. Attach a readable file to each course in a "Resources" item at the end. Same pattern as the BBE 101 and 102 transcripts uploaded that morning. Learners can download it, Claude reads it through the connector, nothing about the SCORM lesson changes.
3. Put the lesson text in the SCORM lesson's description field above the player. Readable by the connector, but learners see a wall of text above the slides.

Also flagged: the readable copy already exists on disk, since a SCORM package is just the lesson's HTML plus helper files zipped up. The AIT files are 300 KB of mostly fonts and styling, so a stripped plain-text version was offered as a "Knowledge Base" folder.

**Mark's pick.** Option 2. He had been thinking along those lines, and confirmed himself in Claude Code that the connector reads an uploaded Word file back in full. Merly agreed the scope is Advanced Industry Training only. Mark: one document, a "Resources" section in each course, and pitch it as an accessibility option too.

**Adjustments agreed.** One document per course, not one for all of AIT, because Part 1 learners should not be handed Part 2 content and Claude answers better knowing which course a file belongs to. Leave the Final Exam questions and the activity answers out, otherwise the accessible version is also the answer key. The accessibility claim is honest only with real headings so a screen reader can jump by lesson and section.

**Name.** Mark asked for something prettier, "some sort of a workbook", and a name. Three offered: Course Companion (goes alongside the course, does not replace it), Reader's Edition (implies the whole course in prose, which it is not), Workbook (Mark's word, but there are no exercises to fill in). Course Companion chosen.

**Scope narrowed by Mark.** The full video transcript already exists, so that becomes its own resource, "Transcript of the video", as HTML. Apply activities and quizzes stay SCORM and are not converted. So the Companion is the Read lessons only, slide by slide, on-screen text plus narration.

**Format.** HTML page in the course rather than a Word download: opens like any lesson, works on a phone, Ctrl+F finds anything, contents links jump to each slide, best format for screen readers, and the connector returns a lesson's HTML in full in one call, which beats a download link. Styled like the BBE 101 lessons, which are proven in Skilljar. Word remains available later for printing if anyone asks.

**One source finding.** For Lessons 2 to 6 the recorded narration differs from the written scripts, sometimes a lot. The Companion takes the narration from the caption files, since that is what learners hear.

Mark added the Resources sections in both courses and the build went ahead. Files and tools are in `Banking Expertise - Advanced Industry Training\Course Companion`.
