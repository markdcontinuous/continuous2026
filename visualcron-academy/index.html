Part 1: For the LMS team

How the site works

The home page is built automatically from course tags. Nobody builds category pages by hand. Tag a course correctly and it appears in every place it belongs:

Where on the siteWhat puts a course there
Featured Courses row (under the blue header)tag vcfeatured
Label on a Featured card (NEW, POPULAR, WEBINAR...)tag vcnew, vcpopular, or vc + any word
Find training for your role (the six cards)tag vcrole:<role>
Looking for a place to start? (three courses)tag vcessential
All courses page, and each topic's own pagetag section:<topic> (or vcsection:<topic>)

Every course with a section: tag appears on the All courses page (the hero's Browse courses button, or "Or browse all courses" under the role cards). Each topic also gets its own page automatically.

Tag reference

All VisualCron tags start with vc, so they sort together in Skilljar's tag list, apart from other programmes' tags. (section: still works, for tags made before this rule.)

TagEffect
vcsection:<topic> or section:<topic>Puts the course in a topic. One per course. Topics below.
vcrole:<role>Lists the course under a role card. A course can have several. Roles below.
vcessentialOne of the three "place to start" courses. Tag three; if more are tagged, the first three show.
vcfeaturedPuts the course in the Featured row.
vcnewYellow NEW label on its Featured card.
vcpopularBlue POPULAR label on its Featured card.
vc<word>A label with that word, white by default. Add a colour to the end: navy, blue, yellow, sky. Example: vcwebinarnavy shows a navy WEBINAR label.

Labels only show in the Featured row, and only on courses that also have vcfeatured. A featured course with no label tag shows FEATURED.

Labels are one word. A space splits a tag in two, and Skilljar removes the colons when it puts tags on the page (it keeps hyphens). Write vcbestseller, not vc best seller.

Topics (for vcsection:)

TagTopic
vcsection:startStart here
vcsection:jobsJobs, tasks and flow
vcsection:triggersTriggers and scheduling
vcsection:filesFiles and managed file transfer
vcsection:connectionsConnections and integrations
vcsection:notificationsEmail and notifications

A topic only appears once it has at least one course. A course with a topic that isn't on this list (a typo, or a new topic not yet set up) goes under More courses at the bottom of All courses. It is never lost.

Roles (for vcrole:)

TagRole card
vcrole:evaluateI'm evaluating VisualCron
vcrole:builderI build and schedule jobs
vcrole:integrateI connect VisualCron to other systems
vcrole:alertsI need to know when jobs run or fail
vcrole:bankingI run automation at a bank or credit union
vcrole:accountsI manage our account, users and licenses

A role card only appears once it has at least one course, and it shows its course count.

Switching over from the built-in lists: until the first course is tagged with any vcrole: tag, the role cards use a list written into the code. As soon as one course carries a vcrole: tag, the tags take over for all roles. Tag every course for its roles in one sitting, or some cards will briefly empty. vcessential works the same way.

Adding a tag to a course

Only published courses can be tagged, so publish first.

Several courses at once: Domains & Publishing → Tags → New Tag (or click an existing tag) → type the tag → Published Courses (+) → tick the courses → Save.

One course: Course Management → Courses → the course → Manage Course → Publish course → Tags.

Everyday tasks

Add a new course (one video)

  1. Create the course in Skilljar with one lesson. Use the lesson HTML in source/lesson-video-template.html: replace VIDEO_ID (twice) and VIDEO_TITLE (once).
  2. Title the course after the video. Write the short description from what the video says. Nothing the video doesn't say goes in the description.
  3. Publish it to academy-poc.visualcron.com, on the main catalog page.
  4. Tag it: one vcsection: topic, any vcrole: roles it serves.
  5. Optional: vcfeatured plus a label, or vcessential.
  6. Check the home page, All courses and the role cards with Ctrl+Shift+R.

No code changes and no catalog pages to build.

Add a batch in an existing topic

Same as above for each course. They appear in the topic's row on All courses and on the topic's page.

Add a batch in a new topic

  1. Check the topics table first. Ten topics are already set up, and most VisualCron subjects fit one of them.
  2. If it's truly new, ask for it to be added (Part 2 has the one-line change). Supply a name, a one-line description, and which icon to use.
  3. Meanwhile, tag the courses with the new topic anyway. They show under More courses and move to their own row once the topic is added.

Add a new role

Ask for it to be added (Part 2). Supply the card text ("I ..."), a short key for the tag, and which icon to use. Then tag courses vcrole:<key>.

Feature a course, or change a label

Add or remove vcfeatured, vcnew, vcpopular or a vc<word> label tag. Remove vcnew when a course stops being new; about a month is a sensible default.

Remove a course from somewhere

Remove the tag. The course leaves that place and stays everywhere else it's tagged.

Rules

  1. Tags do the work. Don't build catalog pages per category. Topic and role pages are automatic.
  2. Paste only from theme/. Those are the four files that go into Skilljar. Never paste from source/.
  3. Change code only through source/, then rebuild (Part 2). Don't edit the files in theme/ by hand.
  4. Test before pasting. Every change is checked on a saved copy of the live page first.
  5. Skilljar's snippet boxes stop at about 50,000 characters, and they cut off without warning. If the whole site suddenly loses its styling, this is the first thing to check. Current sizes are in Part 2.
  6. Course text comes from the video. Titles, descriptions and summaries only say what the video says.
  7. Brand colours only for labels: navy, blue, yellow, sky, white. No red (reads as an error) or green (reads as completed).
  8. Mark signs off changes to the home page layout.

Header logo: Theming → Themes → VisualCron Academy → Header → Header logo. The file is reference/original-logos-with-strapline/2025-visualcron-colour-1024x148-a-continuous-company.png. Without a logo the site has no way back to the home page from a lesson.

Check before anything goes live

  • Home page: Featured, role cards (with counts), place to start, documentation banner.
  • All courses shows every course, and the count matches Skilljar.
  • A topic page and a role page open, and their breadcrumbs lead back.
  • Featured labels show the right words and colours.
  • A lesson: the whole video fits on screen, and the logo leads home.
  • Footer: logo shows, links work.
  • Phone width: menu button works, cards stack.

Part 2: For whoever changes the theme

Files

theme/     the four files pasted into Skilljar (built, compact; never edit by hand)
source/    the full, commented working copies; edit these
tools/     minhead.pl and mincode.pl build theme/ from source/
reference/ saved live pages, logos, Skilljar examples
SKILLJAR-BUILD-STATUS.md  running build log: every decision and why

Build after every change, from the project folder:

perl tools/minhead.pl source/global-head-snippet.html theme/global-head-snippet-READY.html
perl tools/mincode.pl source/global-code-snippet.html theme/global-code-snippet-READY.html

minhead.pl strips comments and indentation and prints css identical: yes when the styling is unchanged apart from whitespace. Sizes on 28 September: head snippet about 47,100 characters, code snippet about 32,000. The head snippet is close to the 50,000 cap. Before adding much more styling, look for rules the pages no longer use and remove them. (The section-row styles are still in use by All courses.)

Settings inside source/global-code-snippet.html

All near the top, or at the start of the home page block:

SettingWhat it holdsChange it when
TAG = 'vc'The tag prefixReusing the code for another catalog
SECTIONSTopic key, name and one-line description, in display orderAdding a topic
ICONSOne embedded icon per topic key (also used by role cards)Adding a topic
ROLESRole key, icon (a topic key), card text, and a built-in course list used until vcrole: tags existAdding a role
ESSENTIALSBuilt-in "place to start" list, used until vcessential tags existRarely
SUBCATALOGSOptional: send a topic to a hand-built Skilljar page instead of its automatic pageNormally empty

Adding a topic is one line in SECTIONS, for example { key: 'reports', title: 'Reports and dashboards', lead: '...' },, plus an icon in ICONS under the same key. Without an icon it falls back to the "other" icon.

Adding a role is one entry in ROLES: { key: 'auditor', icon: 'admin', title: 'I audit our automation', courses: [] }.

How the home page is built

  • The script runs on catalog pages only. The home page is detected by the body class sj-page-catalog-root.
  • Skilljar still renders the full course grid (#catalog-courses). The script reads it as its source and hides it.
  • Views are built on the home page from the URL hash, with no Skilljar page behind them: #all, #subject-<key>, #role-<key>. A hash change reloads the page to rebuild.
  • The grid also holds tiles that aren't courses: nested catalog pages (sj-catalog-page) and hidden search templates (search-only, data-type="-l"). These are filtered out.
  • The script also swaps Skilljar's FREE for a Start pill, adds the Featured labels, draws the animated hero mark, and fills the footer logo (from visualcron.com's own white logo URL).

Testing without the live site

  1. Save the live home page: curl works when Edge headless is blocked by CloudFront. Use a normal browser user-agent string.
  2. Put the new compact snippets in place of the old ones in the saved copy, and add <base href="https://academy-poc.visualcron.com/"> so Skilljar's styles load.
  3. Open it in Edge headless with --dump-dom plus a small probe script that counts roles, rows and labels, and with --screenshot. Try #all, #subject-start and #role-builder as well.
  4. To test tags, edit data-tags on a few tiles in the copy. Tags arrive comma-separated with punctuation removed, e.g. sectionjobs,vcfeatured,vcrolebuilder.
  5. If Edge started from Git Bash returns nothing, run it from PowerShell.

The header looks broken in offline copies, and thumbnails are blank. Both are because Skilljar's scripts don't run offline; ignore them.

Skilljar behaviour to remember

  • Tags reach the page with their colons removed: section:start becomes sectionstart. Hyphens are kept (application-owners stays as it is); the code removes them too.
  • The snippet boxes cut off silently at about 50,000 characters, and a cut-off stylesheet takes all the styling with it.
  • Skilljar's own heading sizes override ours on catalog pages, so our heading sizes carry !important.
  • Skilljar lays the catalog out again after our script runs, so anything that measures the layout (the carousel arrows) must re-check on resize and after load.
  • There is no setting for the FREE text on cards; the script replaces it.
  • A nested catalog page shows up as a tile in its parent catalog.
  • The API (through the Skilljar connector) can create courses and lessons and, since 1 October 2026, publish them to a domain. It cannot tag courses, set course images, or add courses to a catalog page, so those are dashboard work. A timed-out create_courses may still have created everything, so check before retrying.
  • Lesson pages need a login, so they can't be saved or tested offline like the catalog. Test lesson styling on a mock that follows the live layout, then confirm on the live site.
