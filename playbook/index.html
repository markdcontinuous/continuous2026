Catalog Uplift Playbook

How to give another Continuous Skilljar catalog the treatment VisualCron Academy got: a home page that works like a front door, with courses placed by tags instead of hand-built category pages. Written from the VisualCron build, 23 to 28 September 2026.

For the LMS team planning an uplift, and for whoever builds it.

What we're repeating

Before the uplift, a catalog is usually one long list of courses, or a set of category pages built and kept up by hand. After it:

  • The home page is a front door. It has a hero, a Featured row, role cards ("Find training for your role"), a few courses to start with, and a link to the documentation. It is not a list of everything.
  • Tags place every course. One tag sets the topic, others set roles, featuring and labels. Adding a course means tagging it, not editing pages.
  • Topic and role pages build themselves from the tags, along with an All courses page. There are no category pages to maintain.
  • The theme looks like the product's own website: its colours, fonts, logo and footer links.

Before building: find out

These are open questions for every new catalog. Answer them first.

  1. Is it its own Skilljar domain with its own theme? The code snippets belong to a theme. If two catalogs share one theme, the code has to tell them apart (for example by domain name). That isn't built yet.
  2. What does it hold today? List every course, and every hand-built category page and which courses it contains. The category pages become topics.
  3. Which tags already exist? Pick a prefix no other programme uses, so tags stay easy to find in the shared tag list: short and unique, like vc.
  4. Who are the learners? This sets the roles. For VisualCron we took them from the product site's audiences, plus banks and credit unions for Continuous customers.
  5. Whose brand is it? A product site (like visualcron.com) or the Continuous brand? Take colours, fonts and logos from the real source, not from memory.
  6. Who signs off? For VisualCron it was Mark, with Merly's feedback.

Steps

  1. Take a brand inventory. Colours, fonts, logo (with and without strapline), favicon, footer links. VisualCron's is in BRAND-EXTRACTION.md and DESIGN-SYSTEM.md as a model.
  2. Copy the VisualCron source/ and tools/ folders into a new project folder, with empty theme/ and reference/ folders.
  3. Change the settings in source/global-code-snippet.html: TAG, SECTIONS, ICONS, ROLES (with empty built-in lists), ESSENTIALS (empty), and the Featured row heading if wanted.
  4. Change the look in source/global-head-snippet.html: the colour and font variables at the top (section 1). Most rules read those variables, so few other lines need touching.
  5. Rewrite the hero (source/catalog-header.html) and the footer (source/footer.html) with the catalog's own text and links. Check any hero or card copy against the courses. Nothing goes in that the content doesn't support.
  6. Build the theme/ files with tools/minhead.pl and tools/mincode.pl. Check both are under 50,000 characters.
  7. Test offline on a saved copy of the catalog's live home page (method in MANAGING-THE-ACADEMY.md, Part 2). Check the home page, #all, a topic and a role, at desktop and phone widths.
  8. Tag the courses in Skilljar: one topic each, roles, essential, featured, labels. Do all role tags in one sitting (see the switching note in the management guide).
  9. Paste the theme files and upload the header logo. Without a logo there's no way back to the home page from a lesson.
  10. Check live with the checklist in the management guide. Then retire the old hand-built category pages. Remove them from the main catalog first, then delete them.
  11. Write the catalog's own management guide by copying MANAGING-THE-ACADEMY.md and changing the tag, topic and role tables.

Mistakes we already made, so the next build doesn't

What happenedWhat to do
Section tags never matched, and the page stayed a flat listSkilljar removes the colons: section:start arrives as sectionstart. Match on that form.
The whole site lost its styling after a pasteThe snippet box cut the file off at about 50,000 characters. Paste the compact -READY builds, and check sizes before pasting.
Headings came out small on the live site but fine offlineSkilljar's CSS overrides heading sizes. Use !important, and test with Skilljar's real CSS loaded.
Carousel arrows missing liveSkilljar re-lays out the catalog after our script runs. Re-check on resize, load and scroll.
A new course would have appeared nowhereThe home page had no route to courses outside Featured and roles. The All courses page and automatic topic pages fix this. Keep them.
Every card said FREENo setting exists. The code snippet replaces it with Start.
Lessons had no way homeNo header logo had been uploaded. Upload it.
Two search buttons in the headerSkilljar's left button duplicates the search box. Hidden on desktop catalog pages, kept on phones and lessons, where it has other jobs.
Video lessons needed scrollingThe 16:9 player was sized by width. Cap its width by the window height.
A catalog page showed as a course tileNested catalog pages appear as tiles in the parent catalog. The code filters them out.
Working files got mixed up with paste filestheme/ holds only files to paste; source/ holds working copies.
Wording rules changed mid-build (Continuous strapline off, then back on)Record brand decisions in the build log with the date, so nobody re-applies an old rule.

Tools and facts

  • Skilljar API (through the connector): creates courses and lessons in bulk and, since 1 October 2026, publishes them to a domain. It cannot tag, set course images or add courses to a catalog page, so those are dashboard work. A timed-out bulk create may still have succeeded, so check before retrying.
  • Saving the live page: curl with a browser user-agent works when headless Edge is blocked.
  • Offline testing: Edge headless, --dump-dom with a probe script, and --screenshot. Run from PowerShell if Git Bash returns nothing.
  • Build log: keep a SKILLJAR-BUILD-STATUS.md in every project, and write every decision and finding into it the day it happens.
